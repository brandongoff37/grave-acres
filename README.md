# Grave Acres

Grow crops, raise a zombie horde, and raid the towns next door. A web app you can install on Android and iPhone.

## Install on your phone
- **Android (Chrome):** open the link, then tap ⋮ → **Install app** (or **Add to Home screen**).
- **iPhone/iPad (Safari):** open the link, tap **Share** → **Add to Home Screen**.

It opens full-screen like a normal app and works offline after the first load. Progress is saved on each device.

## Hosting
Static files only (index.html, manifest.json, sw.js, icons). Serve over HTTPS, e.g. GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
